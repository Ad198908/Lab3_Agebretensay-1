Lab 3 requires us to generate and commit a requirements.txt file with the "pip freeze > requirements.txt" command, which I did, but the file is empty.  What is it supposed to look like and is it a problem that its empty even if the program works?
> 💡 `pip freeze` captures the exact version of any dependencies installed with `pip install`. You need at least the `pathlib` dependency for the lab. So if `pip freeze > requirements.txt` doesn't include a line for `pathlib` then either you didn't `pip install pathlib` yet, or else the version of `pip`/`python` used to install `pathlib` isn't the same one you're calling `pip freeze` with, keep trying.
